# 老年综合评估（CGA）报告生成框架

> **文档说明**
> 1. 本文为《老年智能预问诊系统需求分析与功能规划》作业的报告框架章节，定义 CGA 报告的结构、内容来源与**由 21 张量表自动汇总生成**的机制。
> 2. 文中阈值与结论模板为**示例／工程建议值**，用于说明规则配置方式，**不构成诊断结论**；实际使用须以量表正式版本与临床规范为准。
> 3. 报告中的所有自动结论一律标注 **"系统生成，需接诊医生复核"**。

---

## 一、报告定位与生成原则

### 1.1 报告定位

CGA 报告是预问诊阶段 21 张量表采集结果的**结构化汇总产物**，服务于三个用途：一是让医生在接诊前快速掌握患者的多维健康状态与风险；二是让患者与家属获得可读的评估要点与随访指引；三是作为随访对比的基线档案。

### 1.2 生成原则

| 原则 | 说明 |
|---|---|
| 自动汇总 | 报告由 21 张量表作答数据经计分、归集、判定自动生成，非人工拼凑 |
| 维度聚合 | 先量表得分、再维度结论、后综合结论，形成"分—合"结构 |
| 风险前置 | 高风险预警置于报告醒目位置，避免被淹没在汇总数据中 |
| 可追溯 | 每个结论均可回溯到具体量表与原始作答 |
| 医生终审 | 算法不单独定论；高风险条目与最终结论须经医生确认 |
| 完整性可见 | 量表缺失时明确标注"结论不完整"及其影响范围 |

---

## 二、报告整体结构

报告按以下 8 大板块顺序组织：

```text
CGA 报告
├── 1. 患者基本信息
├── 2. 各量表得分汇总
├── 3. 各维度评估结论
├── 4. 综合结论
├── 5. 风险预警
├── 6. 干预建议
├── 7. 随访计划
└── 8. 医生参考摘要
```

---

## 三、各板块详解

### 3.1 板块一：患者基本信息

| 字段 | 来源 | 说明 |
|---|---|---|
| 姓名、性别、年龄 | 登录身份／身份识别 | 年龄用于共病指数等指标的计算修正 |
| 就诊科室／主诉 | 智能预问诊 | 主诉为结构化后的症状摘要 |
| 既往史、用药史、过敏史 | 预问诊＋病历带入 | 标注来源（患者自述／病历带入／家属旁证） |
| 身高、体重、BMI | 患者自填或设备测量 | 用于营养与肌少症相关判定 |
| 评估时间、评估方式 | 系统记录 | 标注自填／代填比例与设备项目完成情况 |
| 采集完整性 | 系统统计 | 显示"已完成 X/21"，缺失清单可见 |

### 3.3 板块三：各维度评估结论

将 21 张量表按 **12 个维度**归集后，给出每个维度的综合结论与证据来源。维度归集见第四章 4.2 节。

| 维度 | 来源量表 | 维度结论（示例） | 证据摘要 |
|---|---|---|---|
| 躯体功能与活动 | BADL、IADL、SPPB、肌少症、步速 | 中度功能受限，存在肌少症可能 | SPPB 偏低＋步速 <0.8 m/s＋握力低于阈值 |
| 认知功能 | MMSE／Mini-Cog、AD8 | 认知需关注，建议进一步评估 | MMSE 低于界值＋AD8 阳性 |
| 心理情绪 | GDS-15、GAD-7、PHQ-9 | 存在抑郁倾向，焦虑轻度 | GDS-15 ≥5，PHQ-9 中度 |
| 营养 | MNA-SF | 存在营养不良风险 | MNA-SF 落入 8～11 区间 |
| 衰弱与共病 | CFS、Charlson | 衰弱前期，共病负荷中等 | CFS＝4，共病指数中等 |
| 跌倒与安全 | Morse 跌倒评估 | 跌倒中风险 | 总分落入 25～44 |
| 睡眠 | PSQI | 睡眠质量差 | PSQI >7 |
| 疼痛 | 疼痛 NRS | 中度疼痛 | NRS ≥4 |
| 排泄功能 | 尿失禁、便秘 | 轻度失禁困扰，功能性便秘 | ICIQ 1～5，便秘标准阳性 |
| 口腔 | 口腔健康 | 咀嚼功能需关注 | GOHAI 低分 |
| 感官 | 视听力 | 视力下降 | 矫正视力偏低 |
| 社会支持 | SSRS | 社会支持不足 | 总分偏低，独居 |

> 说明：上表为结论模板示例。

### 3.4 板块四：综合结论

综合结论由各维度结论按"**共病叠加＋风险优先**"原则聚合生成，通常表述为：

1. **总体功能状态**：综合功能分级（如"中度功能受限"）；
2. **主要问题清单**：按风险从高到低列出 3～5 项突出问题；
3. **可干预性判断**：区分可逆／可干预问题（如营养、疼痛、睡眠、抑郁）与需长期管理者（如衰弱、共病）；
4. **完整性声明**：若量表缺失，注明"基于已完成 X/21，结论不完整"。

综合结论明确标注：**"本结论由系统汇总生成，需接诊医生复核后方可作为诊疗依据。"**

### 3.5 板块五：风险预警

风险预警独立成块并高亮展示，按等级分类：

| 预警等级 | 触发条件（示例） | 展示方式 | 处置要求 |
|---|---|---|---|
| 红色（高） | PHQ-9 第 9 题阳性（自伤风险）、CFS ≥6、Morse ≥45、MMSE 低于重度界值 | 置顶红色高亮＋即时提醒 | 医生必须确认并记录处置动作 |
| 橙色（中） | GDS-15 ≥10、SPPB ≤8、MNA-SF ≤7、步速 <0.6 m/s | 醒目橙色标注 | 医生复核并纳入干预 |
| 黄色（低） | PSQI >7、NRS ≥4、ICIQ 中度、社会支持偏低 | 正常列表标注 | 建议干预，可随访观察 |

> 预警规则由管理端可视化配置，支持按机构调整阈值。

### 3.6 板块六：干预建议

干预建议按维度生成候选建议，由医生编辑确认，示例：

| 维度 | 系统候选建议（示例） | 医生可操作 |
|---|---|---|
| 心理情绪 | 建议进一步评估抑郁程度，必要时转诊心理／精神科 | 确认／修改／补充 |
| 营养 | 建议营养门诊评估，补充蛋白质与能量摄入监测 | 确认／修改／补充 |
| 躯体功能 | 建议制定抗阻与平衡训练计划，评估康复介入 | 确认／修改／补充 |
| 跌倒 | 建议居家环境改造（防滑、扶手、照明）与助行器具评估 | 确认／修改／补充 |
| 疼痛 | 建议明确疼痛部位与病因，制定镇痛方案 | 确认／修改／补充 |
| 共病 | 建议梳理多药共用（潜在不适当用药）并优化处方 | 确认／修改／补充 |

### 3.7 板块七：随访计划

| 项目 | 内容 |
|---|---|
| 随访对象 | 患者本人／家属（经授权） |
| 随访时间 | 由医生设定（如 1 周、1 个月、3 个月） |
| 随访内容 | 选定需追踪的量表（如 GDS-15、PSQI、MNA-SF、Morse） |
| 提醒方式 | 患者端推送、家属提醒、短信 |
| 结果处理 | 回填后生成趋势对比；异常趋势触发再次评估提示 |

### 3.8 板块八：医生参考摘要

面向医生的一屏式摘要，是报告中使用频率最高的部分，内容包含：

1. **一句话概览**：年龄＋主诉＋综合功能分级；
2. **核心问题**：3～5 项按风险排序的问题；
3. **异常维度列表**：仅列异常维度，正常维度折叠；
4. **需重点关注项**：红色与橙色预警项；
5. **数据可信度提示**：自填／代填比例、矛盾条目、缺失量表；
6. **建议方向**：可干预点与建议转诊方向。

## 四、21 张量表 → 报告的自动汇总生成机制

### 4.1 生成链路（数据流）

```text
21 张量表作答数据
  → ① 完整性校验（是否齐备、是否需到院补测）
  → ② 逐表计分（按管理端配置的计分规则）
  → ③ 分级判定（按界值划分等级）
  → ④ 维度归集（量表 → 12 个维度）
  → ⑤ 维度结论合成（同维度多量表互参）
  → ⑥ 风险预警计算（阈值命中 → 预警等级）
  → ⑦ 综合结论聚合（共病叠加＋风险优先）
  → ⑧ 干预建议映射（维度 → 候选建议）
  → ⑨ 随访计划生成（预警与异常维度 → 随访项）
  → ⑩ 报告渲染（8 大板块 + 医生摘要 + 版本留痕）
```

每一步的结果均写入报告并保存中间值，保证结论可回溯到原始作答。

### 4.3 计分与分级判定

- **计分规则来源**：由管理端"计分与阈值配置"维护，支持按项赋值、加权、反向计分与计数判定四类；
- **分级判定**：按配置的界值区间映射到等级（正常／需关注／异常／高风险），不同量表界值可差异化配置；
- **多量表互参**：同一维度内多张量表结论不一致时（如"SARC-F 阴性但握力低于阈值"），采用"**保守优先**"原则取更需关注的结果，并标注冲突来源提示医生复核。

### 4.4 结论／预警／建议映射规则（示例）

| 维度 | 判定依据（示例） | 维度结论模板 | 预警等级 | 建议方向 |
|---|---|---|---|---|
| 心理情绪 | GDS-15 ≥5 或 PHQ-9 ≥10 | 存在抑郁倾向 | 橙／红（第 9 题阳性为红） | 进一步评估与心理干预 |
| 营养 | MNA-SF 8～11 | 营养不良风险 | 橙 | 营养门诊评估 |
| 躯体功能与活动 | SPPB ≤8 或 步速 <0.8 | 功能受限 | 橙 | 抗阻与平衡训练 |
| 认知功能 | MMSE 低于界值 且 AD8 阳性 | 认知需关注 | 橙 | 认知专科评估 |
| 跌倒与安全 | Morse ≥45 | 跌倒高风险 | 红 | 防跌倒干预与居家改造 |
| 衰弱与共病 | CFS ≥5 | 衰弱 | 橙／红（≥6 为红） | 老年医学综合管理 |
| 睡眠 | PSQI >7 | 睡眠障碍 | 黄 | 睡眠卫生与行为干预 |
| 疼痛 | NRS ≥4 | 中度以上疼痛 | 黄／橙 | 明确病因与镇痛 |
| 排泄功能 | ICIQ ≥6 | 失禁困扰 | 黄 | 类型评估与盆底管理 |
| 社会支持 | SSRS 总分偏低 | 社会支持不足 | 黄 | 家庭与社会资源介入 |

> 上表为规则配置示例，实际阈值由管理端按机构规范设定。

### 4.5 完整性校验与缺失处理

| 情形 | 报告处理 |
|---|---|
| 21 张全部完成 | 生成完整报告，综合结论有效 |
| 部分量表缺失 | 标注"基于已完成 X/21，结论不完整"，并列出缺失清单及影响的维度 |
| 设备类项目未完成 | 标记"到院补测"，该维度结论标注"待补测后更新" |
| 敏感条目患者跳过 | 该量表标注"条目缺失"，预警判定采用保守估计 |
| 自填与代填矛盾 | 不自动覆盖，生成"数据冲突提示"供医生复核 |

### 4.6 版本与留痕

- 每次报告生成记录**模板版本**与**规则版本**，规则变更后可重新生成历史报告并保留旧版本；
- 医生对条目与结论的修改全部留痕，包含修改人、时间、前后值，支持回滚核查；
- 报告可导出为文档或 PDF，供院内流转与归档。

## 六、合规与边界说明

1. **不作诊断**：报告为评估汇总，不构成诊断或治疗结论，最终判断权在接诊医生；
2. **医生终审**：所有维度结论、综合结论与风险预警均需医生复核确认后生效；
3. **隐私最小化**：报告内容按角色分级可见，敏感维度对非授权人员脱敏；
4. **数据可追溯**：所有自动生成内容可回溯至原始作答与规则版本；
5. **示例数据声明**：本文所有示例数值均为演示用途，非特定机构真实患者数据。
