# 老年智能预问诊系统需求分析

> **文档说明**
> 1. 本文为《老年智能预问诊系统需求分析与功能规划》作业的需求分析章节，承接痛点分析结论。
> 2. 文中涉及的数据、比例与指标均为"示例／公开调研数据"或工程建议值，用于说明需求方向，**不代表特定机构的真实统计结果**。
> 3. 需求编号规则：`FR-端-序号`（功能性需求）、`NF-序号`（非功能性需求）；端标识 `P`＝患者端、`F`＝家属侧、`D`＝医生端、`A`＝管理端。

---

## 一、项目背景与目标

### 1.1 项目背景

1. **老龄化与多重共病并存**：老年患者普遍合并多种慢性病，常规单科门诊难以覆盖其躯体功能、认知、心理、营养、社会支持等多维问题，老年综合评估（CGA）因此成为规范化诊疗的基础。
2. **预问诊环节长期失效**：现有预问诊产品或依赖纸质表单，或直接套用面向中青年的通用问诊流程，未考虑老年人的操作、认知与心理特征，导致完成率低、数据质量差。
3. **21 张量表带来结构性挑战**：CGA 需采集 21 张量表，题目多、耗时长、采集方式混杂（自填／代填／设备辅助／医生复核），若缺乏适配老年人的产品设计，采集几乎无法在诊前完成。
4. **数字化与适老化政策要求**：国家推进信息无障碍与互联网应用适老化改造，要求面向老年人的数字服务具备大字、语音、简洁流程与人工兜底能力。
5. **医院侧效率诉求**：医生希望在接诊前获得结构化、可汇总的患者信息与风险评估，把诊室时间从"问病史"转向"做决策"。

### 1.2 建设目标

**总体目标**：构建一套面向老年人的智能预问诊系统，使老年患者及其家属能够在就诊前，以低操作门槛、低认知负荷、可中断可续填的方式完成智能预问诊与 21 张 CGA 量表采集，并自动汇总生成老年综合评估报告，供接诊医生复核与决策。

**具体目标**：

| 序号 | 目标 | 度量方向（示例／公开调研数据或工程建议值） |
|---|---|---|
| G1 | 提升采集完成率 | 老年人独立或在少量协助下完成率显著提升 |
| G2 | 提升数据完整性 | 21 张量表完整率达较高水平，缺失者可续填 |
| G3 | 降低操作门槛 | 核心流程 ≤ 2 级，关键操作免图形验证码 |
| G4 | 保障数据可信 | 敏感维度多源交叉 + 医生复核，降低低报漏判 |
| G5 | 缩短医生问诊准备时间 | 诊前即可获得结构化报告与风险预警 |
| G6 | 支持可配置与可扩展 | 量表、题项、阈值可由管理端配置，无需改版发版 |

### 1.3 项目范围

- **包含**：患者端（含家属代填通道）的预问诊与量表采集、CGA 报告自动汇总、医生端报告查看与复核、管理端量表与规则配置、数据统计。
- **不包含**：诊断与处方决策（由医生承担）、医保结算、院内检验检查开单、硬件设备的生产与采购（仅定义设备辅助的接入与引导方式）。

## 二、用户角色分析

### 2.1 角色总览

| 角色 | 主要使用场景 | 使用端 | 数字素养 | 核心诉求 | 主要痛点 | 设计侧重 |
|---|---|---|---|---|---|---|
| 老年患者 | 就诊前自助预问诊与量表作答 | 患者端 | 低～中，差异大 | 少操作、说得清、答得完 | 操作障碍、认知与表达困难、心理障碍 | 语音优先、大字大按钮、断点续填、私密作答 |
| 家属／照护者 | 代填、旁证、协助操作 | 患者端（家属通道） | 中～高 | 快速代填、信息准确、流程省心 | 不了解老人内心感受、担心信息偏差 | 代填授权、旁证标注、来源可追溯 |
| 接诊医生 | 接诊前查看报告、复核、随访 | 医生端 | 高 | 结构化、可信、可快速定位风险 | 数据缺失、量表失真、需重新问诊 | 报告摘要、风险高亮、复核与确认 |
| 系统管理员 | 量表配置、规则维护、运营 | 管理端 | 高 | 灵活配置、可审计、可统计 | 量表版本变更、阈值调整需发版 | 可视化配置、版本管理、权限与审计 |

### 2.2 老年患者

- **基本特征**：60 岁以上，视觉与听觉功能下降，部分存在轻度认知障碍，慢病多、用药多，智能设备使用经验差异极大。
- **核心诉求**：不想学、怕点错、怕麻烦人；希望"能说就不打字"，中途可以有事先走、回头接着答。
- **需求要点**：语音为主要输入方式；题目口语化并可解释；敏感问题可私密作答或跳过；明确的进度与结束反馈。
- **成功判定**：在少量协助下完成智能预问诊与 21 张量表，且自述"不难、没被打断得莫名其妙"。

### 2.3 家属／照护者

- **基本特征**：多为子女，时间碎片化，可能不在老人身边；对老人病史与用药掌握程度不一。
- **核心诉求**：能代替老人完成操作；不确定的信息能如实标注；敏感问题不让老人尴尬。
- **需求要点**：代填授权与身份绑定；代填内容与患者自填内容分别标注来源；对矛盾信息提示而非自动覆盖。
- **成功判定**：在老人无法独立完成时，家属可在同一流程内接管并完成采集。

### 2.4 接诊医生

- **基本特征**：老年科／全科／门诊医生，接诊量大，需在有限时间内获取高质量病史。
- **核心诉求**：一屏看到结论与风险；可快速核验原始作答；不合适处能修改并留痕。
- **需求要点**：CGA 报告结构化展示；风险预警高亮并可处置；量表复核与结论确认；随访计划管理。
- **成功判定**：接诊前即可依据报告形成初步判断，诊室内减少重复问诊。

### 2.5 系统管理员

- **基本特征**：信息科或业务运营人员，负责量表与规则维护。
- **核心诉求**：量表可增删改、阈值可调、报告模板可配，且变更可追溯、可回滚。
- **需求要点**：可视化量表／题库配置；计分规则与阈值配置；报告结论映射配置；权限、日志与审计。
- **成功判定**：新增或调整一张量表、修改一个阈值无需开发发版。

## 三、功能性需求

### 3.1 患者端与家属侧（P／F）

| 编号 | 需求名称 | 需求描述 | 优先级 |
|---|---|---|---|
| FR-P-01 | 极简登录与身份识别 | 支持手机号验证码、身份证＋人脸或家属代登录，禁用以图形拖动验证码为主的校验方式 | 高 |
| FR-P-02 | 双通道交互 | 语音与文字并列可用，支持方言／口音容错，识别失败时给出标准化选项兜底 | 高 |
| FR-P-03 | 智能预问诊 | 采集主诉（口语化→结构化）、现病史、既往史、用药与过敏史，支持历史病历带入 | 高 |
| FR-P-04 | 21 张量表采集 | 提供 21 张 CGA 量表入口，按维度与采集方式分组呈现 | 高 |
| FR-P-05 | 断点续填与自动保存 | 每题实时保存；退出、超时、换设备后可原地续填，展示已完成清单 | 高 |
| FR-P-06 | 设备辅助测试引导 | 对握力、小腿围、SPPB、步速、视听力等提供视频示范、操作校验与重复测量 | 高 |
| FR-P-07 | 进度可视化与激励 | 以"已完成 X/21"等明确进度、阶段反馈与语音播报维持作答动机 | 中 |
| FR-P-08 | 报告查看（患者视角） | 以大字号与语音播报呈现可读的评估结论与建议 | 中 |
| FR-P-09 | 人工／家属协助入口 | 常驻"一键转人工"与"请家人帮我"入口，实现机器为主、人工兜底 | 高 |
| FR-P-10 | 隐私与用途告知 | 前置隐私承诺、数据用途与呈现范围说明，敏感维度支持私密作答 | 高 |
| FR-F-01 | 代填授权与绑定 | 家属经授权绑定后可代老人操作，权限边界清晰并留痕 | 高 |
| FR-F-02 | 代填与旁证标注 | 代填／旁证内容与患者自填分别标注信息来源，矛盾时提示而非覆盖 | 高 |
| FR-F-03 | 家属查看与提醒 | 经授权查看报告要点，并接收随访与复诊提醒 | 中 |

### 3.2 医生端（D）

| 编号 | 需求名称 | 需求描述 | 优先级 |
|---|---|---|---|
| FR-D-01 | 待诊列表与报告查看 | 展示已完成预问诊的患者，一屏查看 CGA 报告核心结论 | 高 |
| FR-D-02 | 量表复核与确认 | 可查看原始作答、修改明显失真条目、确认或驳回量表结论，全程留痕 | 高 |
| FR-D-03 | 风险预警处置 | 高亮显示抑郁、自杀风险、跌倒、衰弱等预警项并记录处置动作 | 高 |

| FR-D-05 | 干预建议编辑确认 | 在系统建议基础上由医生编辑、确认或补充干预方案 | 中 |
| FR-D-06 | 随访计划管理 | 制定随访时间、内容与提醒方式，支持随访结果回填 | 中 |
| FR-D-07 | 历史报告对比 | 支持同一患者多次评估结果纵向对比，观察功能变化趋势 | 中 |

|---|---|---|---|

| FR-A-02 | 题库与题项管理 | 管理题目、选项、口语化文案与解释，支持批量导入导出 | 高 |
| FR-A-03 | 计分规则与阈值配置 | 可视化配置计分方式、分级界值与风险阈值 | 高 |

| FR-A-05 | 用户与权限管理 | 角色、机构、功能权限与数据权限的分级管理 | 中 |
| FR-A-06 | 数据统计与看板 | 采集完成率、平均耗时、量表缺失分布、预警分布等运营统计 | 中 |
| FR-A-07 | 日志与审计 | 记录配置变更、权限变更、数据访问与医生修改行为，可追溯可回滚 | 高 |

## 四、非功能性需求

| 编号 | 类别 | 需求描述 | 指标／约束（示例或工程建议值） |
|---|---|---|---|
| NF-01 | 适老化与无障碍 | 大字、大按钮、高对比、语音优先；兼容系统级大字与屏幕朗读 | 正文不低于 18pt 等效；触控热区 ≥ 48×48dp；对比度达无障碍要求 |
| NF-02 | 性能 | 页面与接口快速响应；长任务不阻塞交互 | 常规接口响应 ≤ 2 秒；接口超时（建议 ≤ 5 秒）触发降级提示与重试，不丢失已答内容 |
| NF-03 | 可靠性与数据不丢失 | 断点续填、离线暂存、异常恢复 | 逐题实时保存；异常中断后恢复率 100%；支持弱网暂存 |
| NF-04 | 安全与隐私合规 | 最小必要采集、分级授权、加密传输与存储、全程审计 | 符合个人信息保护与医疗数据管理相关要求；敏感数据脱敏展示 |
| NF-05 | 兼容性 | 多终端、多系统可用 | 支持主流 Android／iOS、微信小程序／公众号、平板与社区自助终端 |
| NF-06 | 可扩展与可配置 | 量表、题项、阈值、模板均可配置 | 新增／调整量表无需开发发版；配置变更灰度生效 |
| NF-07 | 易用性与可达性 | 零学习成本、人工兜底可达 | 核心流程 ≤ 2 级；任一页面 ≤ 2 步内到达人工协助入口 |
| NF-08 | 合规与伦理 | 知情同意、评估结果不作诊断结论 | 首次使用需确认知情同意；算法结论一律标注"需医生复核" |
| NF-09 | 可维护性 | 接口地址、规则参数集中管理，便于统一修改 | 接口基础地址集中定义；规则与文案可热更新 |

## 五、核心业务流程

### 5.1 流程一：患者发起预问诊

`患者/家属扫码或打开入口` → `极简登录（验证码/人脸/代登录）` → `知情同意与隐私告知` → `选择就诊科室或由系统推荐` → `进入智能预问诊`

- 关键点：登录环节禁用图形验证码类校验；未完成登录时允许"先作答、后绑定"，避免因登录失败阻断采集。
- 异常分支：登录失败 ≥ 2 次 → 自动提示"一键转人工"。

### 5.2 流程二：智能预问诊（主诉与病史采集）

`语音或文字采集主诉` → `口语化→结构化映射（症状、部位、时长、程度）` → `带入历史病历与既往用药` → `核对过敏史与关键风险（跌倒、失禁、认知）` → `生成预问诊小结`

- 关键点：以结构化选项替代开放式长文本；不确定项标记为"待医生确认"，不阻断流程。
- 异常分支：语音识别失败 → 切换标准化选项；老人不愿回答 → 允许跳过并记录。

### 5.3 流程三：21 张量表分组采集与断点续填

`按维度与采集方式分组（自填组／代填组／设备组／医生复核组）` → `智能排序（高风险、易疲劳维度前置）` → `逐张量表作答（每题实时保存）` → `需设备项目提供视频示范与操作校验` → `中途可退出，恢复后原地续填` → `提交前完整性校验（缺失项提示影响）`

- 关键点：分组分段降低单次负担；设备辅助项目给出场地与协助提示；避免把认知、情绪类量表排在末位以减轻疲劳效应。
- 异常分支：家庭无法完成设备项目 → 标记为"到院补测"，由医生在院完成并回填。

### 5.4 流程四：数据汇总与 CGA 报告生成

`21 张量表作答数据归集` → `按量表计分规则计分` → `按维度归集（躯体／认知／心理／营养／共病／睡眠／疼痛／社会支持等）` → `阈值判定与风险预警计算` → `按"得分→结论／预警／建议"映射生成内容` → `生成 CGA 报告（含患者基本信息、得分汇总、维度结论、综合结论、风险预警、干预建议、随访计划、医生摘要）`

- 关键点：报告由数据自动汇总生成，非人工拼凑；所有结论标注"需医生复核"。
- 异常分支：量表缺失过多 → 报告标注"结论不完整"，并提示续填或到院补测。

### 5.5 流程五：医生端查看与复核

`医生打开待诊列表` → `查看 CGA 报告与医生参考摘要` → `核验原始作答` → `修改失真条目 / 确认或驳回量表结论` → `处置风险预警` → `编辑并确认干预建议` → `制定随访计划`

- 关键点：高风险条目（抑郁、自杀风险、认知、跌倒）必须经医生确认方可生效；所有修改留痕可追溯。
- 异常分支：医生提出缺失量表 → 触发"补充采集"任务，推送给患者或到院补测。

### 5.6 流程六：随访管理

`医生设定随访时间与内容` → `系统按计划推送提醒（患者端／家属）` → `患者或家属回复随访问题` → `随访结果回填并生成趋势` → `异常趋势触发再次评估提示`

- 关键点：随访结果与原报告形成纵向对比，用于观察功能变化，形成"评估—干预—随访"闭环。

## 六、需求与痛点对应关系（可追溯性）

| 痛点 | 对应功能性需求 | 对应非功能性需求 |
|---|---|---|
| P1 操作障碍 | FR-P-01、FR-P-02、FR-P-07 | NF-01、NF-07 |
| P2 表达与认知困难 | FR-P-03、FR-P-04、FR-D-02 | NF-08 |
| P3 心理障碍 | FR-P-10、FR-F-02、FR-D-03、FR-D-02 | NF-04、NF-08 |
| P4 系统适老化不足 | FR-P-05、FR-P-09、FR-F-01、FR-A-01 | NF-01、NF-03、NF-05、NF-06 |
| P5 21 张量表采集难点 | FR-P-04、FR-P-06、FR-D-06 | NF-03、NF-06、NF-09 |
